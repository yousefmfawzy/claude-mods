# claude-mods

Install: `/plugin install context-meter --marketplace yousefmfawzy/claude-mods`

## Every cloud session (recommended)

Add to the environment's setup script (environment menu → Edit → Setup script):

```sh
claude plugin marketplace add yousefmfawzy/claude-mods
claude plugin install context-meter@claude-mods
```

Or per repo: copy `.claude/settings.json` from this repo into the project.
